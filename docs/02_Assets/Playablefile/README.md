# DreamSlayer

## How to play

1. Keep all files and folders in this directory together.
2. Double-click `DreamSlayerV2.exe` to start the game.

This is the published Windows 64-bit version. You do not need to rebuild the
project or install .NET separately. To share the game, send the entire
`Playablefile` folder (or a ZIP of it), not just the `.exe`.
